社区 ​

WlzShield 致力于打造 安全、有趣、易集成 的新一代行为验证解决方案。

为了项目的持续发展、服务器的维护以及新功能的研发，我们欢迎并感谢您的每一份支持。同时，我们也建立了一个活跃的开发者社区，供大家交流接入心得与技术探讨。

💬 加入社区 ​

我们在开发过程中难免遇到各种环境兼容性问题。加入官方交流群，您可以：

  1. 第一时间获取更新：了解 WlzShield 的最新特性与安全补丁。
  2. 技术答疑：遇到集成报错或 API 签名问题，群内有开发者互助。
  3. 提出建议：您的需求（如新的验证码玩法）可能会被纳入下个版本的开发计划。

联系方式 ​

官方交流群 (WeChat)

个人微信 (WeChat)

🤝 贡献代码 ​

WlzShield 拥抱闭源但免费的精神。如果您发现了 Bug 或有更好的实现思路，欢迎提交 PR 或 Issue。

  • 文档修正：帮助我们完善 前端组件文档 或 API文档。
  • 多语言翻译：协助完善 lang 参数对应的国际化配置。
  • 逆向建议：贡献基于当前验证码版本的 逆向代码。
  • 防护建议：给与我们更多的防护建议。

让我们一起构建更安全的 Web 交互体验！
